ARNOX CORE - KOMANDE
====================

1. POKRETANJE U TERMINALU
-------------------------

Otvori Terminal, pa:

  cd /Users/arnel/Desktop/JARVIS-DESKTOP/JARVIS-OS-V.2
  source .venv/bin/activate
  JARVIS_CLI=1 python main.py

Ili kraće, sa aktiviranim .venv:

  jarvis

Pokretanje bez dva pljeska (startni clap gate):

  JARVIS_SKIP_CLAP_GATE=1 JARVIS_CLI=1 python main.py

Provjera bez pokretanja GUI-ja (sigurni self-test, piše izvještaj u .qa-artifacts/):

  jarvis --self-test

Gašenje iz terminala: Ctrl+C, ili glasom / tekstom (vidi dolje).


2. TIPKOVNI PREČACI
-------------------

  F4              Uključi / isključi mikrofon (mute)
  F6              Minimiziraj / vrati prozor
  F11             Puni ekran
  Ctrl+/          Pomoćni panel sa prečacima
  Ctrl+M          Kompaktni režim
  Ctrl+Shift+C    Otvori / zatvori Command Center
  Ctrl+Shift+T    Promijeni boju teme
  Enter           Pošalji komandu iz polja za unos
  Esc             Zatvori overlay / odbaci


3. FIKSNE GLASOVNE NAREDBE
--------------------------

Interfejs:
  "open the Command Center"        otvori Command Center
  "close the Command Center"       zatvori Command Center
  "open settings"                  otvori podešavanja
  "change theme"                   promijeni temu
  "change graphics quality"        promijeni kvalitet grafike (low / medium / high)
  "compact mode"                   kompaktni režim
  "fullscreen"                     puni ekran
  "show shortcuts"                 prikaži prečace

Kontrola zvuka i prekid:
  "stop", "wait", "hold on", "pause", "cancel that"   prekine govor ili zadatak
  "interrupt"                                         odmah zaustavi govor

Sleep / pauza (crveni mod, mikrofon isključen):
  "go to sleep", "standby", "vai in pausa", "modalità mute", "pauza", "spavaj"
  (na bilo kojem jeziku; ARNOX kratko potvrdi, pa ode u crveno)
  Buđenje: ukucaj bilo šta u polje za unos, ili reci "Arnox".
  U sleep modu zvuk se NE šalje Googleu. Samo lokalni detektor na računaru sluša riječ "Arnox".
  Ako se budi prerijetko ili prečesto, podesi prag: ARNOX_WAKE_THRESHOLD (npr. 1e-30 strože, 1e-50 osjetljivije).
  Automatski: 60 s tišine = žuta tema, 120 s = crvena (sleep).

Gašenje aplikacije (samo na izričit zahtjev):
  "quit arnox", "goodbye arnox", "goodbye arnox please"
  "shut down arnox", "turn off arnox", "go offline"
  (stare varijante sa "jarvis" također rade)
  ARNOX prvo kaže oproštajnu rečenicu, pa se tek onda gasi.

Poruke i e-mail:
  "check my messages"              pročitaj nedavne poruke
  "send a message to ..."          pošalji poruku (traži potvrdu)
  "reply to that"                  pripremi odgovor (traži potvrdu)
  "is Gmail connected"             status Gmail veze
  "show my unread Gmail"           nepročitani mailovi
  "search Gmail for ..."           pretraga (npr. from:alex@example.com)
  "prepare an email to ..."        otvara Gmail compose, NE šalje
  "approve that email" / "cancel that email"

Pretraga i istraživanje:
  "search the web for ..."         brza pretraga (traži dozvolu)
  "do deep research on ..."        duboko istraživanje (pita: pozadinski ili vidljivo)
  "what is the status of my research"
  "cancel research task <ID>"

Prezentacije:
  "create a presentation about ..."
  "what is the status of my presentation"
  "cancel presentation task <ID>"

Zadaci i pozadinski poslovi:
  "task status" / "what is running"

Dokumenti i prilozi:
  "read this PDF" / "what is in this file"   pročitaj i sažmi dokument (PDF, Word, Excel, CSV, JSON, HTML, PowerPoint, txt)
  "show attachments of that email"            lista priloga uz mail
  "read the attachment" / "read attachment 2" pročitaj prilog (preuzima se privremeno, pa se briše)
  "save the attachment"                       snimi prilog u Downloads/ARNOX Attachments
  Izvršne datoteke (.exe, .dmg, ...) se nikad ne otvaraju. Skenirani PDF bez teksta se prijavi kao takav.

Workspace (dokumenti unutar ARNOX prozora):
  "show this PDF in ARNOX" / "open report.pdf on screen"     PDF u novom tabu (zum, pretraga, stranice)
  "show the spreadsheet" / "open sales.xlsx in the workspace"  CSV/Excel kao tabela (pretraga, sortiranje, listovi)
  "close the tab"                    zatvori trenutni tab (ili Ctrl+W dok je workspace otvoren)
  "hide the workspace"               nazad na ARNOX jezgro (tabovi ostaju otvoreni)
  "show the workspace"               vrati otvorene tabove
  Dugme "BACK TO CORE" u workspaceu radi isto što i "hide the workspace".
  Web stranice se još NE mogu prikazati unutar ARNOX-a. Spotify se ne može (nema Widevine DRM).

Web u workspaceu (https stranice i HTML fajlovi):
  "show my Gmail in the workspace" / "open mail.google.com"    https stranica u tabu unutar ARNOX-a
  "open report.html"                                           lokalni HTML fajl u tabu (samo taj fajl)
  Samo https (i http na localhost) se otvara. file:, javascript: i drugi se odbijaju.
  Iskačući prozori se otvaraju kao novi tabovi u workspaceu, ne kao prozori.

Tiha pretraga (bez prikaza, odgovor dobijaš glasom):
  "what is the weather in Sarajevo today"     traži u pozadini, workspace se NE otvara
  "sakrij workspace"                          samo sakriva, tabovi ostaju

Fajlovi i ekran:
  "open <putanja ili fajl>"        otvori fajl ili folder
  "what is on my screen"           analiza ekrana (jednom po zahtjevu)
  "take a screenshot"

Muzika i video:
  "play <pjesma>", "pause", "next", "previous"   (Spotify je default)
  "play <video> on YouTube"

Ostalo:
  "set a reminder for ... to ..."  podsjetnik
  "weather in <grad>"              vrijeme (traži dozvolu za web)
  "change voice"                   promijeni glas (Puck, Charon, Kore, ...)
  "change my name"                 promijeni ime korisnika

WEB APLIKACIJA (PWA) — LOKALNO POKRETANJE
=========================================

Potrebna su dva terminala. Oba počinju iz foldera projekta.

Terminal 1: API (FastAPI, baza je SQLite u ./tmp, Redis nije potreban)

  cd /Users/arnel/Desktop/JARVIS-DESKTOP/JARVIS-OS-V.2
  source .venv/bin/activate
  alembic upgrade head
  JARVIS_ENV=development uvicorn api.server:app --reload --port 8000

  Provjera: otvori http://localhost:8000/health, treba pisati ok.

Terminal 2: web klijent (Next.js)

  cd /Users/arnel/Desktop/JARVIS-DESKTOP/JARVIS-OS-V.2/web
  cp .env.example .env.local
  npm install
  npm run dev

  Otvori http://localhost:3000 u pregledniku.

Napomene:
  - Prvi put: u web aplikaciji napravi nalog i unesi svoj GEMINI_API_KEY (čuva se šifrovan).
  - Mikrofon u pregledniku radi na localhost-u. Sa telefona preko Wi-Fi-ja (http://IP:3000) mikrofon NE radi;
    treba HTTPS adresa (npr. Vercel nakon deploya).
  - Produkcijski build i PWA (service worker) rade samo u "npm run build" + "npm start", ne u "npm run dev":
      npm run build
      npm start          (http://localhost:3000)
  - Zaustavljanje: Ctrl+C u oba terminala.
  - Ako alembic javi grešku o putanji ./tmp, napravi folder: mkdir -p tmp

  Ako alembic upgrade head javi "table users already exists":
    baza je već napravljena (API je sam kreirao tabele u razvoju). Samo označi verziju:
      alembic stamp head
      alembic upgrade head
    Ako nemaš podataka koje želiš sačuvati, možeš i obrisati bazu i ponovo pokrenuti:
      rm tmp/jarvis_web.db && alembic upgrade head
